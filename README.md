# 🚀 Right Track

Right Track is a web platform that helps users discover the right skills at the right time based on their age and interests.

---

## 🌟 Features

- 🎯 Personalized skill suggestions
- 📊 Interactive dashboard
- 📚 Skill guidance (What, Why, Action)
- 📈 Progress tracking UI
- 💡 Daily recommendations

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- (Optional: Flask - backend)
